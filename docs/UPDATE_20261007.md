# 2026-10-07 公开整合更新

## 发布范围

把已合并并在 Windows 运行验证的新版功能整理到团队公共仓库。以原公共 `main` 为基础创建新提交，不携带私人仓库的 Git 历史，也不发布其原始实验日志、检查点、个人资料或本机部署报告。

源码、通用文档、依赖配置、评测 / 训练准备工具和小型固定 COCO 资料保留。训练准备工具存在不等于已经训练成功或具有精度提升。本次不新增权重、虚拟环境、缓存、视频及 build；原公共仓库已有文件没有作为清理对象删除。

## 功能合并

- 四种输入：摄像头、本地视频、单张图片和图片文件夹；保留中文图片路径、翻页及每张图片独立编号。
- YOLOE-26S / 26L / 26X / 11L 与 Grounding DINO Tiny 文本检测。默认 26S、640、FP32。
- YOLOE SAVPE：上传完整参考图、框选目标、填写显示名称，用参考物体视觉特征检测，不再是旧颜色模板筛选。DINO 不支持这个视觉页面。
- SAHI 320/512/640、20% 重叠、最多 9 块串行；与旧四分块互斥，默认关闭。
- ByteTrack 同类目标编号、原有暗光补检 / 仅增强预览及独立最大框数控制。
- 摄像头独立采集、单帧待检 / 待显示缓冲、最新帧替换；离线视频仍逐帧处理。
- 显示 FPS、读帧到 Qt 提交的延迟、滚动 p50/p95 和替换计数。摄像头录像时间轴用重复处理帧保持时长，MP4 无音轨。
- Windows / Linux 资源锁与内存检查，保持 3GiB 推理预算、单模型、batch=1、加载前 4GiB 空闲显存、推理前 1GiB 空闲显存、至少 1.5GiB 可用 RAM，以及 OOM 停止策略。

## 合并兼容

新 GUI 使用 `GroundingDINOEngine` 的固定文本阈值解码；旧 `pan_deng/` 评测使用兼容类 `GroundingDinoEngine`，保留逐类别 token 打分和按类别 NMS，同时接入资源检查与框数上限。后处理配置不同，不能把旧 AP 直接标成新 GUI 的 AP。

旧 `requirements-grounding-dino.txt` 转向当前 DINO 依赖，防止重新引入 Transformers 5.x。Windows 无符号链接权限的测试用目录解析夹具保留全部断言，不通过增加跳过来掩盖失败。

## 验证与限制

Windows 完整本地合并版已运行 199 项回归：198 项通过，1 项缺少完整原始 COCO 标注缓存而跳过。实际 CUDA 串行检查了文本、SAHI、SAVPE、新 GUI DINO 和旧评测 DINO 五条路径；这些只是功能检查，部分单图返回 0 框，不能称为准确率验证。

原生 Qt 中 YOLOE → DINO → YOLOE 切换、两张中文路径图片及文件夹翻页通过，YOLOE / DINO 分别处理了四帧视频并显示 `person1/person2`。夹具是同一人像的两份拼接，不证明身份识别或遮挡后永不换号。

独立公开发布目录已重跑全部 199 项：198 项通过、1 项缺少原始标注缓存跳过；`pip check` 无依赖冲突，Qt 启动及默认控件检查通过。13 个核心运行文件与本地实测合并版的 SHA-256 一致。测试日志与预览仅在本地，不随公开提交发布。

没有在本轮重跑完整 COCO 精度评价、真实摄像头优化前后对照、长时录像压力测试或训练。摄像头最新帧机制改善的是排队策略，不代表模型前向计算变快，也没有本轮实测 FPS / AP 提升。

模型微调与自动标注页面仍为开发中；未实现中英文界面切换。历史原始实验记录留在本地，公开说明不引用它们作为本轮新测结果。
