# 合成暗光定量评价

项目章程要求“量化暗光处理对暗画面检测召回率的提升”。此前只有定性前后对比图和 `validate_improvements.py` 的无标注框数对照（框数不是准确率）。`tools/evaluate_lowlight.py` 用人工 COCO 真值，在同一批图片的合成暗光版本上比较五种条件，并给出配对 bootstrap 置信区间。

状态：

- **已验证**：2026-10-28 在本机 RTX 5060 Laptop GPU（CUDA）上完整运行 4 次（84 图 × 4 个暗度；最后 2 次为提交版代码），所有指标、bootstrap 区间和合成暗图 SHA-256 逐位一致。加权 COCO 实现与 pycocotools 对每个条件的 AP / AP50 / AP75 / APsmall / APmedium / APlarge / AR100 均逐项一致。mini_eval 子集的原图 AP 为 0.5953，与 2026-10-04 文本模式结果（0.595）数值相同，但协议不同：本工具用 NMS IoU 0.45 / max_det 300，基线为 0.5 / 100；预测框 158 对 161（图 242060、559956、484978 各少 1 个），AP 恰好相同，不算同协议复现。新增 14 项 CPU / mock 单元测试。
- **未验证**：真实夜间或暗光摄像头视频；YOLOE-26L、无提示 PF、视觉提示、Grounding DINO；SAHI 与暗光同时开启；0.65 以外的增强强度和其他噪声参数；240 图 10 类 COCO 子集（见“数据”）。
- **开发中 / 后续**：带人工框的真实暗光测试集（例如 ExDark，或按场景分组自采并人工标注的课室 / 实验室夜间视频）。

## 合成暗光

对每张 8 位 BGR 图片：

1. 用 gamma 2.2 近似 sRGB 反变换到线性域：`x = (I / 255)^2.2`；
2. 曝光缩放 `k`；
3. 加 Poisson 散粒噪声与 Gaussian 读出噪声：`y = Poisson(k·x·N) / N + N(0, σ²)`，`N = 1000` 个光电子对应原曝光白电平，`σ = 0.001`；
4. 截断到 [0, 1]，按 1/2.2 重新编码，四舍五入量化为 8 位。

这是常用的 Poisson–Gaussian 传感器噪声模型 [Foi 2008]。散粒噪声方差 `x/N = 1e-3·x` 取 Brooks 等人采样范围 [1e-4, 1.2e-2] 的对数中点，读出噪声由其读出 / 散粒噪声关系在该点给出 [Brooks 2019]。暗光目标检测研究也用“曝光缩放 + 噪声 + 量化”合成暗图 [Cui 2021]；更早的增强工作用 gamma 压暗并加噪声 [Lore 2017]。本实现做了简化：没有反向白平衡、色彩矩阵和去马赛克，gamma 2.2 只是 sRGB 曲线的近似，三个通道的噪声相互独立。

随机数流为 `numpy.random.default_rng([6008, 级别序号, 图片 ID])`，与图片顺序和 `--limit` 无关；每张暗图的 SHA-256 写入 report.json。

| 级别 | 曝光 k | 显示域亮度系数 k^(1/2.2) | 平均亮度（原图 0.418） |
|---|---:|---:|---:|
| L1 | 0.25 | 0.533 | 0.222 |
| L2 | 0.12 | 0.381 | 0.158 |
| L3 | 0.06 | 0.278 | 0.115 |
| L4 | 0.02 | 0.169 | 0.070 |

平均亮度是 BT.601 灰度均值 / 255。L4 是在任务给出的三级之外增加的“很暗”一级，用来覆盖增强器最强工作的区间。

## 五种条件

| 条件 | 送入检测器的图像 |
|---|---|
| 原图（参考） | 未压暗原图 |
| 暗图，不增强 | 合成暗图 |
| 暗图 + 旧 CLAHE | `validate_improvements.old_clahe`（LAB L 通道，clip 2.5，8×8），原样导入 |
| 暗图 + 自适应增强后检测 | `AdaptiveLowLightEngine.process(暗图, 0.65)` 的输出 |
| 应用双路径 | 直接调用 `OpenVocabEngine.process_frame(暗图, enhancer=AdaptiveLowLightEngine(), supplement_dark=True)`：先检测暗图，再以 `max(conf, 0.45)` 检测增强图，用 `merge_supplementary` 合并 |

每张静态图片都新建增强器，相当于镜头切换，不把曝光平滑带到无关图片。检测器为 YOLOE-26S 文本提示 `bottle, cup, cell phone`，imgsz 640，NMS IoU 0.45（界面默认），max_det 300，batch 1，CUDA，一次只加载一个模型。

## 指标

- **AP 协议**：置信度阈值 0.05，pycocotools bbox，IoU 0.50:0.95，maxDets 100：AP、AP50、AP75、APsmall / medium / large、AR100。
- **界面默认阈值 0.40**：IoU 0.50 下的召回率与精确率，crowd 匹配不计。单次检测条件直接取 0.05 结果中 ≥ 0.40 的框；NMS 只会被更高分框抑制，所以这与用 0.40 重跑相同。双路径的合并结果取决于保留了哪些原图框，因此在 0.40 下重新调用 `process_frame`。工具逐帧核对：双路径中原图来源的框与“暗图 0.05 结果再过滤到 0.40”完全一致（不一致帧数 0）。
- **配对按图 bootstrap**：种子 20261028，2000 次有放回抽取 84 张图，所有条件共用同一抽样；95% 百分位区间，不做多重比较校正。抽样用逐图匹配结果加权累计，与复制图片后重跑 pycocotools 等价（单元测试核对）。某类在一次抽样中没有正例时，该次总指标记为无效（本次 2000/2000 次均有效）。
- **增强耗时**：只计增强调用本身的 CPU 墙钟时间，在加载模型之前、同一进程内对 336 张暗图（84 × 4）交替测量 CLAHE 与自适应，重复 3 次。

## 解读

1. **合成暗光明显降低检测效果。** AP 从 0.455 降到 0.401（L1）、0.365、0.330、0.234（L4），四级区间都不含 0；L4 在界面阈值下的召回率从 0.505 降到 0.258。
2. **三种增强都没有带来可确认的 AP 提升。** 所有“增强 − 暗图”的 ΔAP 区间都包含 0，点估计在 −0.009 到 +0.012 之间；最大的是 L2 自适应 +0.012 [−0.004, +0.027] 和 L2 旧 CLAHE +0.012 [−0.010, +0.032]。在最暗的 L4，把增强图直接送检测器反而降低界面召回：−0.029 [−0.060, −0.003]；区间刚好不含 0，且没有做多重比较校正，应视为弱证据。
3. **增强只恢复了部分亮度。** L4 暗图平均亮度 0.070，自适应后 0.154，旧 CLAHE 后 0.165，远低于原图 0.418。原因之一是增益上限 `1 + 2 × strength`（默认 2.3）和 gamma 下限；更亮也不等于更易检测，因为噪声和 8 位量化损失的细节无法恢复。
4. **双路径在 AP 协议下与暗图完全相同。** 补检只接受 ≥ 0.45 的增强图框，且与任一已保留原图框同类 IoU ≥ 0.45 或任意类 IoU ≥ 0.8 就丢弃。阈值 0.05 时原图低分框几乎覆盖所有位置，四级都没有一个增强框进入结果，所以 ΔAP 恒为 0（区间 [0, 0] 是设计使然，不是“稳定提升”）。
5. **界面阈值 0.40 下，双路径只多找回极少目标，同时增加误报。** 四级共新增 19 个 +E 框：5 个命中人工框、12 个误报、2 个落在 crowd 上。召回提高 0 / +0.007 / +0.004 / +0.007（275 个框中最多多找回 2 个），精确率下降 0.004–0.033，L4 下降的区间不含 0。因为原图框总被保留，双路径不会降低召回；与“直接检测增强图”相比，它在 L4 的召回高 +0.036 [+0.012, +0.066]。
6. **对章程问题的回答。** 在这个合成协议、这个模型与默认强度下，暗光阶段**没有可测量地提高检测召回或 AP**。报告应把自适应增强定位为显示辅助；双路径是保守选择（不降低召回、默认不改变原图框），但代价是第二次检测和少量误报。“暗光处理提升了检测率”的说法目前没有证据支持。
7. **小样本波动。** 只看 24 图 mini_eval 子集时，自适应的点估计更高（L3 AP 0.452 → 0.490），合并 84 图后只剩 +0.004 [−0.015, +0.023]。不要只引用子集结果。

YOLOE 训练时的亮度扰动增强可能使其对整体变暗较稳健，这只是一个可能解释，本实验没有检验。

## 局限

- 合成暗光不是夜间实拍：没有真实传感器噪声、ISP / 降噪、运动模糊、点光源、色偏或自动曝光。真实暗光是否有同样结论仍未验证。
- 84 张图、277 个框、3 个类别，场景有限；bootstrap 不能增加独立场景。共 4 级 × 5 组比较 × 6 个指标，未做多重比较校正，单个区间刚好不含 0 的结果（如 L4 双路径精确率、L4 自适应增强的界面召回 −0.029 [−0.060, −0.003]）应谨慎解读。
- 84 张图中有 24 张是 `mini_eval`，即此前多次用于方法选择的 24 图开发诊断集（AGENTS.md：不是未见测试集），可能影响过此前对增强方法和参数的选择；另外 60 张来自 `mini_train_probe`。
- 只评价 YOLOE-26S 文本提示、imgsz 640、增强强度 0.65、一个噪声参数组；没有扫描 strength 或噪声水平。
- 静态图片：不涉及跨帧曝光平滑和 ByteTrack，二者可能改变视频中的表现。
- 双路径的 +E 框可能是误报，本实验观察到误报多于命中。
